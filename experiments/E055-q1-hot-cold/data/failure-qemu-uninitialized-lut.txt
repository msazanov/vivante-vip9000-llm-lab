Cause: the first harness main did not copy make_table() into the E039 global
g_table_q1_signs before calling native_simd_group(). The stock SIMD path then
expanded every sign through an all-zero table. This was a harness initialization
failure, not evidence against the Q1 kernel or against A733.

Fix: initialize g_table_q1_signs from make_table() before run_golden(). The
repeated self-test then passed golden_pass=true, golden_cases=18. This failed
artifact is retained so the first red gate is not silently erased.
