# E049c-v2 pre-fix — отклонённая серия

Статус: **REJECTED**. Bonsai не запускался.

Эта серия была снята после первого варианта протокола v2, но до проверки
необычного расположения inherited file descriptors. Обычные target-запуски
дали `status=ok`, однако последующий host-тест воспроизвёл дефект: когда pipe
marker уже имел fd 8, а pipe ACK — fd 9, последовательный `dup2` уничтожал один
из источников. Контроль завершался по timeout с кодом 143.

Поэтому **ни одно числовое значение этой папки не используется как итоговый
результат**. Файлы сохранены как важное evidence неудачной реализации.
Исходник launcher в этой серии имел SHA-256
`c27ded53b4fca2e246ae53182de632c37012aa33c6d8816ae3a269799940ed58`.

После RED-теста оба pipe сначала дублируются выше фиксированного диапазона,
затем атомарно устанавливаются ACK=8 и marker=9; исходный marker закрывается
только когда он не равен 9. Финальная повторная серия находится в
[`../v2-20260814/`](../v2-20260814/).

PMU values здесь являются counts событий ARM PMU, а не количеством DDR-байтов.
