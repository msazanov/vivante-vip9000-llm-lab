# Предварительная проверка гипотезы

Гипотеза: единый детерминированный протокол E047 позволит сравнить скорость
Bonsai и LFM2.5 без смешения токенизаторов и форматов.

Проверены все доступные локальные и remote-tracking ветки инструментом
`tooling/branch_preflight.py`; исходный JSON сохранён в
`data/branch-preflight.json`. Это read-only проверка: fetch, скачивание моделей
и запуск инференса не выполнялись.

Результат повторного v3 preflight после обновления remote-tracking refs,
включая `origin/codex/e049-nsi-calibration` на `5bb2590`: LFM2.5 уже упоминается в
`origin/profiling-foundation` (`docs/evidence/orange-rag-prior-tests.md`).
Точное совпадение `E047-common-benchmark` найдено только в ссылках истории
текущей ветки; это проверяемая self-копия уже созданного каркаса, а не более
ранний независимый эксперимент.
Она намеренно остаётся в `duplicate_decision`, чтобы решение не подменялось
простым флагом «совпадений нет». Новые запуски обязаны переиспользовать этот
контракт и не создавать второй E047-каталог. V3 дополнительно сохраняет точные
SHA refs и self-reference-safe хеш stage-0 Git index по `path/mode/blob OID`.
Валидатор независимо перечитывает фактические refs и корни экспериментов,
пересчитывает duplicate evidence и отвергает устаревший снимок.
