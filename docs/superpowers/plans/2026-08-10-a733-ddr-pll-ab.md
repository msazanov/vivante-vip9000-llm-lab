# A733 DDR PLL guarded A/B runner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать mock-testable, fail-closed runner exact PLL DDR A/B candidate `0x54→0x63` без выполнения записи на реальную плату в этом ходе.

**Architecture:** Один стандартно-библиотечный Python-модуль разделяет policy/validation, backend регистров, watchdog, telemetry sampler, workload runner и append-only JSONL evidence. По умолчанию выполняется только inspect; `apply` требует явного флага, точного полного expected word, target raw `0x63`, confirmation и mock/explicit backend. Реальный backend в этом ходе недоступен и не вызывается.

**Tech Stack:** Python 3 standard library, `unittest`, POSIX `fcntl/os/signal/subprocess`, JSONL с `fsync`; no `shell=True`, no external runtime dependencies.

## Global Constraints

- Реальную плату не трогать: не запускать apply, не писать `/dev/mem`, sysfs, boot config или DT.
- Whitelist: PLL_DDR_CTRL `0x02002020` writable only through guarded backend; DRAM_CLK_REG `0x02002c00` read-only.
- Apply допускает только exact raw pair `0x54→0x63`, сохраняет все остальные биты и требует full original `0xf9005400`.
- Validate enable/lock/LDO/output bits and bounded lock polling/readback; restore full original word in `finally` and on SIGINT/SIGTERM.
- Watchdog is mandatory for apply; successful path performs clean disarm magic-close; boot recovery is documented, not executed.
- Sampler interval is 250 ms and records all thermal zones, cpufreq, clk summary, both registers and safety drift.
- Abort/restore on ≥85 °C, register drift, lock loss, workload failure, timeout or child-process failure.
- Fixed workloads are argv arrays: `taskset -c 0-5 mbw -n 10 256` and bounded `taskset -c 0-5 memtester 128M 1`.
- JSONL events are atomic append records with fsync and include schema version, run ID, host identity, phase, stdout/stderr/rc/time.
